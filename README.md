# MediBed – Live Hospital Bed Availability (Demo Prototype)

> **DEMO DATA** – Not verified real-time hospital availability. Contact the hospital to confirm.

## Project Files
- `index.html` – Home page, Patient Search, and Hospital Dashboard sections.
- `styles.css` – Responsive blue, white, and teal healthcare theme.
- `utils.js` – Timestamp formatting, 24-hour STALE detection, countdown timer formatting, and input validation.
- `data.js` – Fictional demo hospitals (Bhopal, Indore, Jabalpur) and `localStorage` persistence for hospitals and temporary 2-minute demo holds.
- `patient.js` – City search, bed-type filters, availability badges, and 2-minute demo bed holds.
- `hospital.js` – Forms to add new demo hospitals and update ICU, Oxygen, and General bed counts.
- `app.js` – Navigation between Home, Find Beds, and Hospital Dashboard, plus cross-tab sync.

## How to Run in Google Chrome
1. Open the `medibed` folder.
2. Double-click `index.html` to open it directly in **Google Chrome** (no server or API keys required).
